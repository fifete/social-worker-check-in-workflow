# Phase 1: Environment Baseline, Dependencies & Security Guardrails

## Context & Prerequisites
* **Mandatory Reference:** Before executing these tasks, read `design/index.md` to understand the global architectural constraints and UI styling rules.
* **Objective:** Initialize the Vite + React 18+ workspace from scratch, enforce strict dependency security guardrails, install required offline/storage libraries, and configure Tailwind CSS.
* **Execution Boundary:** Do NOT write any application logic, UI components, database wrappers, or Google API integrations during this phase. Focus strictly on environment configuration, build tools, and baseline styling setup.

## Task 1: Project Initialization & Security Guardrail (`.npmrc`)
You must initialize the core React project structure and immediately lock down script execution to protect against supply-chain attacks before pulling any remote node modules.

1. If the root directory does not already contain a Vite project, initialize a new React + JavaScript (or TypeScript) workspace using Vite:
   ```bash
   npm create vite@latest . -- --template react

    ```

2. Immediately create an `.npmrc` file in the root project directory before running any installation commands.
3. Add the following rule to strictly block arbitrary third-party lifecycle script execution during dependency installations:
    ```ini
    ignore-scripts=true

    ```

## Task 3: Package Installation & Deterministic Version Pinning

Install the exact core libraries required for local IndexedDB management, Progressive Web App (PWA) generation, and Tailwind CSS utility styling.

1. Execute the following installation commands in the terminal:
    ```bash
    # Install production runtime dependencies
    npm install idb

    # Install development build and styling dependencies
    npm install -D vite-plugin-pwa tailwindcss postcss autoprefixer

    ```


2. Initialize the Tailwind and PostCSS configuration files:
    ```bash
    npx tailwindcss init -p

    ```


3. **Deterministic Pinning Requirement:** Open `package.json`. You must strip out all semantic versioning prefixes (remove all carets `^` and tildes `~`) across both `dependencies` and `devDependencies`. Every dependency must lock to an exact semantic version string to prevent nested tree drift during future builds.
* *Example of Correct Pinning:* `"idb": "8.0.0"`
* *Example of Incorrect Pinning:* `"idb": "^8.0.0"`

## Task 4: Tailwind CSS Configuration & Theme Tokens

Configure the utility compiler to recognize our design tokens and high-contrast color palette.

1. Open `tailwind.config.js` and configure the content paths and custom brand colors:
```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        brand: {
          emerald: "#059669", // Primary Action / Success
          blue: "#2563EB",    // Google Authentication
          slate: "#0F172A",   // Typography / Text
          amber: "#D97706",   // System Warnings / Offline
          light: "#F3F4F6"    // Surface / Background
        }
      }
    },
  },
  plugins: [],
}

```


2. Open `src/index.css` and replace all existing CSS rules with standard Tailwind directives and our system font baseline:
    ```css
    @tailwind base;
    @tailwind components;
    @tailwind utilities;

    /* Enforce system sans-serif bold baseline and prevent horizontal scroll */
    body {
    @apply font-sans antialiased bg-[#FFFFFF] text-[#0F172A] m-0 p-0 overflow-x-hidden;
    }

    ```

## Task 5: Baseline PWA Vite Configuration

Register the PWA bundler plugin to prepare the application for local Service Worker caching.

1. Open `vite.config.js` (or `.ts`).
2. Import and register `vite-plugin-pwa` alongside the React plugin. Configure the basic standalone manifest scaffolding:
```javascript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { VitePWA } from 'vite-plugin-pwa';

export default defineConfig({
  plugins: [
    react(),
    VitePWA({
      registerType: 'autoUpdate',
      manifest: {
        name: 'Control de Asistencia',
        short_name: 'Asistencia',
        theme_color: '#FFFFFF',
        background_color: '#FFFFFF',
        display: 'standalone',
        orientation: 'portrait'
      }
    })
  ]
});

```
